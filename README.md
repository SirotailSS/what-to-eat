## 📖 项目简介

**“今天吃点啥”** 是一个轻量级的纯前端配菜工具，专为“选择困难症”人群设计。点击「配菜！」按钮，系统会从 **80+ 种食材库** 中随机抽取主料和辅料，并从 **20 种烹饪方式** 中加权随机选取一种做法，组合成一道完整的菜肴。

更有 **5% 概率触发「风味彩蛋」** —— 当辅料为水果/酱料类特殊食材时，会生成类似“榴莲风味清蒸丝瓜”的创意搭配，为枯燥的日常增添一份惊喜（或惊吓）。

---

## ✨ 功能特点

- 🎲 **智能随机搭配**：从 80+ 食材库中抽取主料 + 辅料（自动去重），结合 20 种烹饪方式生成菜名
- ⚖️ **加权随机算法**：烹饪方式按“高频（炒/蒸/煮/炖/烧/拌）→ 中频（煎/炸/烤/汤）→ 低频（爆炒/红烧等）”梯度加权，更符合日常烹饪习惯
- 🎰 **老虎机滚动动画**：点击按钮后三卡快速滚动 24 帧（1.2 秒），仪式感拉满
- 🌈 **5% 风味彩蛋**：当辅料命中“特殊”标签（水果/果酱/巧克力等），触发创意风味前缀
- 📤 **一键分享截图**：基于 `html2canvas` 生成全页截图，移动端支持长按保存，桌面端自动下载
- 📱 **二维码引流**：分享时自动生成二维码，扫码直达工具页面
- 🧰 **工具矩阵入口**：预留「工具百宝箱」和「外卖领券」导航按钮，支持后续扩展
- 📱 **移动端优先**：毛玻璃 UI + 暖色渐变，完美适配手机/平板/桌面

## 🔧 核心逻辑详解

### 1. 食材库 `foodDB`（80+ 种）

按标签分类，支持多维筛选：
- **肉类**：五花肉、猪里脊、排骨、肥牛卷、牛腩等
- **禽类**：鸡腿肉、鸡胸肉、鸭肉等
- **水产**：鲫鱼、三文鱼、虾仁、鱿鱼须等
- **蛋类 / 豆制品**：鸡蛋、豆腐、腐竹等
- **蔬菜**：叶菜、根茎、瓜果、菌菇四大子类
- **特殊食材**（风味彩蛋专用）：草莓、榴莲、巧克力酱、芝士片等 20+ 种水果/酱料

### 2. 烹饪方式库 `cookDB`（20 种，加权随机）

| 权重 | 方式 | 说明 |
|:---:|------|------|
| **4（高频）** | 炒、蒸、煮、炖、烧、拌 | 日常最常用 |
| **2（中频）** | 煎、炸、烤、汤 | 较常用 |
| **1（低频）** | 爆炒、清蒸、红烧、酥炸、香煎、煲、焖、焗、凉拌、羹 | 精细化做法 |

### 3. 菜名生成器 `generateDishName()`

根据不同烹饪分类自动适配命名格式：

| 分类 | 命名格式 | 示例 |
|------|----------|------|
| 炒/蒸/煮/炖/烧/拌 | `主料 + 动词 + 辅料` | 丝瓜清蒸榴莲泥 |
| 煎/炸/烤 | `动词 + 主料 + 配 + 辅料` | 香煎鸡腿肉配冬瓜 |
| 汤类 | `主料 + 辅料 + 汤` | 鲫鱼豆腐汤 |
| **风味彩蛋触发** | `风味食材 + 风味 + 原菜名` | 榴莲风味清蒸丝瓜 |

> **特殊处理**：经典菜名硬编码（如“西红柿炒鸡蛋”“鲫鱼豆腐汤”），避免随机组合破坏经典。

### 4. 风味彩蛋机制

- **触发条件**：随机抽取的辅料带有 `'特殊'` 标签 + 5% 概率
- **效果**：菜名前添加“风味食材 + 风味”前缀（如“草莓风味红烧排骨”）
- **视觉反馈**：分享截图时会包含彩蛋标识
