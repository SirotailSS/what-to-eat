========================================
  项目名称：“今天吃点啥”自动配菜工具
  项目类型：纯前端网页（MVP）
  部署位置：GitHub Pages
========================================

【一、产品描述】
这是一款专为解决家庭做饭“选择困难症”而设计的轻量级网页工具。用户无需纠结“今天吃什么”，只需一键按下“配菜”按钮，系统便会自动从食材库和烹饪库中随机抽取元素，组合成一道完整的菜肴推荐。

【二、实现功能】
1. 核心随机搭配：从“荤菜主料库”中随机选1种主料，从“烹饪方式库”中随机选1种做法，从“素菜辅料库”中随机选1-2种辅料，组合成一道完整的菜名（例如：“爆炒牛肉配土豆”）。
2. 黑暗彩蛋机制：有20%的概率触发“暗黑调料”，从特殊库中随机抽取一种反差食材强行加入（例如：“草莓红烧排骨”），增加趣味性和话题性。
3. 老虎机视觉反馈：点击按钮时，三个展示卡片会快速滚动闪烁，1.2秒后定格显示最终结果，缓解用户等待焦虑。
4. 移动端自适应：界面采用暖色美食风格，完美适配手机和电脑屏幕。
5. 一键部署：纯静态页面，可直接部署至GitHub Pages，免费对外使用。

[ ] === 阶段一：工程准备 (15分钟) ===
  [ ] 子任务 1.1：创建项目文件夹与文件
      - 实现目标：在工作目录下新建一个专属文件夹。
      - 输出结果：包含 index.html、style.css、script.js 三个空白文件，以及一个 assets 文件夹（预留放图片或图标）。
      - 验收方法：用VS Code打开文件夹，确保文件树清晰可见。

[ ] === 阶段二：数据建设 (30分钟) ===
  [ ] 子任务 2.1：构建“主料”数据库
      - 实现目标：在 script.js 中创建数组 meatDB，包含至少15种常见荤菜/蛋白质（如：五花肉、鸡腿、豆腐、鸡蛋、虾仁、牛肉片、鱿鱼须等）。
      - 输出结果：一个完整的JS数组。
      - 验收方法：在浏览器控制台输入 meatDB，能显示数组长度≥15。

  [ ] 子任务 2.2：构建“辅料”与“调料”数据库
      - 实现目标：创建数组 vegDB（土豆、茄子、西红柿、西兰花等，≥15种）和 magicDB（芝士、柠檬、巧克力、咖啡粉等“暗黑元素”，≥8种）。
      - 输出结果：两个独立的JS数组。
      - 验收方法：确保三者数据尽量不重复（例如土豆不要同时出现在主料和辅料里）。

  [ ] 子任务 2.3：构建“烹饪方式”数据库
      - 实现目标：创建数组 cookDB，每个元素是对象 { method: '爆炒', emoji: '🔥', tip: '大火快熟' }，包含至少10种方式。
      - 输出结果：带Emoji和提示的对象数组。
      - 验收方法：cookDB[0].method 能正常取出文字。

[ ] === 阶段三：核心逻辑编写 (30分钟) ===
  [ ] 子任务 3.1：编写基础随机抽取函数
      - 实现目标：封装一个通用函数 pickRandom(arr)，返回数组中的随机一项。
      - 输出结果：function pickRandom(arr) { return arr[Math.floor(Math.random() * arr.length)]; }
      - 验收方法：调用10次，每次返回值都不一样。

  [ ] 子任务 3.2：编写“配菜生成器”主函数
      - 实现目标：编写 generateDish() 函数，分别从主料、辅料、做法中各取一项，组合成对象 { main, veg, cook }。
      - 输出结果：函数返回一个结构化的菜品对象。
      - 验收方法：console.log(generateDish()) 能看到完整的三元素组合。

  [ ] 子任务 3.3：【彩蛋】加入黑暗料理概率
      - 实现目标：在 generateDish() 中，有 20% 的概率从 magicDB 中抽一个调料，强行塞进辅料里（比如“草莓红烧排骨”）。正常情况80%概率只返回常规辅料。
      - 输出结果：常规菜品80%概率，暗黑菜品20%概率。
      - 验收方法：连续点生成50次，观察大概有10次左右多出一个奇怪辅料。
